Version: 0.2.3
Date: 28.11.2026
  Features:
    - Rail layers have a Smoothing setting: higher values let the track stray further from the curve for longer straights and steadier bends. It is 2 by default.
  Changes:
    - Elevated rail layers now take a band as wide as their supports and ramps (4 tiles), so the layers beside them keep clear.
  Bugfixes:
    - Rail supports are planned with their actual footprint, and no longer collide with walls, ramps, other supports or other tracks.
    - Rail supports no longer show a direction arrow in the preview.
    - Rail supports are placed as far apart as the game allows (20 tiles on a straight stretch), instead of about twice as often as needed.
    - Rail track on the inside of a bend tighter than rails can turn now cuts inside the corner, instead of running straight on far past it and swinging back.
    - Blueprints with rails keep their grid on the rail grid.

Version: 0.2.0
Date: 25.11.2026
  Features:
    - Migrated to GUI controls.
    - Added support for Catmull-Rom, Circular, Elliptical and Circular Arc curve construction.
    - Added support for tiles, power poles, solar panels, accumulators, radars, roboports, land mines, lamps, belts, pipes, electric turrets, ammo turrets, fluid turrets, rails, elevated rails.
    - Added support for multiple layers on a single curve.
    - Added support for input inserters for the ammo turrets, taking from an adjacent belt.
    - Added support for fluid input for the fluid turrets, taking from an adjacent pipe.
    - Added support for smart power pole placement, powering electrical network members on the curve while maximizing inter-pole distances.
    - Added support for Force build.
    - Added support for Super force build.
    - Added support for multiple layer presets.
    - Added support for curve import/export.
    - Added support for preset import/export.
    - Added support for blueprint generation.

    - Removed the curve projector entity.
    - Removed Bezier curves (keeping the name because I like it).
